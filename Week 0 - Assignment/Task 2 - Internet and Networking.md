## 🌐 Task 2: Internet and Networking

### Scenario
Your friend is launching an online bookstore named **EpicReads**.  
He asked you to explain how users globally can access his website hosted in Finland.  

### Your Task
- Write a short explanation (**100–150 words**) that includes:
  - **Packet Switching**  
  - **IP Address**  
  - **TCP/IP**  
  - **HTTP/HTTPS**  


## This is how I completed the task 

When my friend launched his online bookstore EpicReads, he hosted the website on a server in Finland so readers from anywhere in the world could access it. When a user types the website address into their browser, the internet first finds the server using its IP Address, which works like the server’s unique digital location. The user’s request then travels across the internet using TCP/IP, the core communication rules that allow devices to send and receive data reliably. The information being sent, such as webpage content and book listings, is broken into smaller pieces through Packet Switching so it can travel efficiently across different network routes before being reassembled at the user’s device. Finally, the browser uses HTTP or HTTPS to request and securely display the website content, allowing readers globally to browse and purchase books from EpicReads.
